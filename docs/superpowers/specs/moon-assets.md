# Moon Visual Assets

- `moon-mark.svg`: original geometric crescent/orbit mark created for this customization.
- `logo.png`, `moon-512.png`, `favicon.ico`: bitmap exports of the same mark, on #07110f.
- `moon-surface.jpg`: NASA/JPL/USGS image PIA00405, downloaded from https://images-assets.nasa.gov/image/PIA00405/PIA00405~orig.jpg and resized to 1000 px for local delivery. No external image requests are needed at runtime.

The image-generation service was unavailable (no enabled image model); these assets are not represented as AI image-generation output.
Original project copyright and AGPL license notices are retained. Upstream links are labeled as upstream resources, not Moon official websites.
