# Moon 登录与品牌设计

状态：用户已确认全站品牌范围 C、视觉方向 A 以及桌面/移动设计稿，进入实施。

## 已确认设计

- 墨黑背景、薄荷青操作色、银白文字，月牙与轨道的新品牌标记。
- 登录页保留普通/LDAP、MFA、验证码重发、语言切换、安全警告与登录后跳转。
- 桌面有品牌视觉区与登录表单；窄屏优先表单。字体、焦点、错误及禁用状态保持可读，低矮屏可滚动。
- 登录、导航、浏览器图标/标题、终端、设置、中英文说明、系统产生的通知统一为 Moon。
- 技术兼容标识、数据库字段、环境变量、外部集成地址和原始许可/版权声明不改。上游资源链接明确标为上游，不伪造 Moon 官网。

## 实施校正

- 设计稿状态文案不是实时数据，正式页面不显示“服务正常”或未经检测的 TLS 承诺。
- 图像生成工具返回没有启用模型；以原创矢量 logo 输出图标及 PNG 浏览器资源，不声称 AI 出图成功。
- 复用 React 16、Ant Design 4、现有 CSS modules 和 Less，不迁移框架。
- 不更改现存 monitor/Step1 用户工作，不执行提交、远程部署或数据迁移。

构建与聚焦登录测试通过。浏览器检查桌面、手机、低矮屏、英文、LDAP、错误、MFA 和键盘提交。登录 API 在浏览器验证中以拦截测试响应隔离，不发送真实凭据。
